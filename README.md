# Prezensa Management System — Final V1

Cockpit de gestão da Prezensa: Início, objetivos estratégicos, indicadores com série histórica editável, Rocks criáveis/editáveis diretamente no Início, L1 (Leadership One), Issues/IDS e preferência Dark/Light.

## Publicação na Vercel
1. Suba esta pasta para um repositório GitHub.
2. Importe o repositório na Vercel.
3. Não é necessário build command; é uma aplicação estática.

## Observação
Esta V1 persiste alterações no navegador via localStorage. A integração efetiva com Microsoft Teams (autenticação Microsoft 365, criação/vínculo da reunião, gravação e transcrição via Graph) requer backend/OAuth e permissões do tenant.
